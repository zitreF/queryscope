Good to know

  • Only processes of your own user that run Java 17 or newer can be attached.
  • Java 21 and newer print a warning about a dynamically loaded agent. Start the app with -XX:+EnableDynamicAgentLoading to silence it, or let QueryScope start the app from the beginning with java -jar queryscope.jar your-app.jar.
  • Requests that are already running when QueryScope attaches are not recorded, new ones are. Classes the app has loaded are instrumented on the spot, which can take a few seconds in a large app.
  • The agent cannot be unloaded: it stays in the app until the app stops.
